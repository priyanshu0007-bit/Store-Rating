# ⭐ Store Rating App

A modern full-stack MERN-style web application where users can browse stores, submit ratings, and manage dashboards based on user roles.

---

## 🚀 Live Demo

🌐 Frontend: [https://store-rating-y86w.vercel.app](https://store-rating-y86w.vercel.app)

💻 GitHub Repository: [https://github.com/priyanshu0007-bit/Store-Rating](https://github.com/priyanshu0007-bit/Store-Rating)

---

# ✨ Features

## 🔐 Authentication & Authorization

* JWT-based Login System
* Protected Routes
* Role-Based Access Control

---

## 👨‍💼 Admin Dashboard

* View all users
* Add new stores
* Delete stores
* Manage platform data

---

## 👤 User Dashboard

* Browse all stores
* Search stores
* Submit ratings
* View average ratings

---

## 🏪 Owner Dashboard

* View owned stores
* Monitor ratings
* Track users who rated stores

---

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/priyanshu0007-bit/Store-Rating.git
```

---

## 2️⃣ Backend Setup

```bash
cd backend
npm install
npm run dev
```

Create `.env` file:

```env
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
PORT=5000
```

---

## 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
